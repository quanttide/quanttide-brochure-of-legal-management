# 算法备案：从判断到拿号的全部关键点

> 依据均核实自官方原文（中国网信网、国家标准全文公开系统），流程与材料部分含申报实践口径，以属地网信办最新要求为准。

## 一、先判断：要不要备案

《生成式人工智能服务管理暂行办法》（2023-08-15 施行）第 2 条：

| 情形 | 结论 |
|------|------|
| 面向境内公众提供生成文本/图片/音频/视频服务 | **适用**，走完整备案 |
| 仅企业内部使用或仅 API 服务企业客户 | 不适用公众服务条款；具有舆论属性的仍需安全评估 |
| 研发应用该技术，未向境内公众提供服务 | 不适用 |

## 二、两件法定义务

《暂行办法》第 17 条把义务拆成两条，依据链：

```
面向境内公众提供
  └─ 具有舆论属性或社会动员能力
       ├─ 安全评估：自行开展、结果负责（2018 年《安全评估规定》第 3 条）
       └─ 算法备案：服务之日起十个工作日内申报（《算法推荐管理规定》第 24 条）
            └─ 大模型备案：随算法备案一并提交（网信办公告口径）
```

- 算法备案系统：https://beian.cac.gov.cn
- 违反第 17 条的罚则见第 21 条：警告、通报批评、责令改正；拒不改正责令暂停服务

## 三、五步流程

1. **判断适用**（上表）
2. **自行开展安全评估**，技术基准：**GB/T 45654-2025《网络安全技术 生成式人工智能服务安全基本要求》**（2025-04-25 发布，2025-11-01 实施，现行）——安全自评估报告按它的语料安全、模型安全、安全措施章节写
3. **属地省级网信办提交**（部分省市有线上入口），预审后上报国家网信办；主体与算法信息在 beian.cac.gov.cn 填报
4. **多轮补正**：书面反馈，按轮次补语料来源说明、关键词库、测试题集
5. **拿号公示**：备案号格式 `网信算备`+数字串+`号`，产品界面显著标注；国家网信办定期公告「已备案信息」可查进度

**时限**：法规未规定审批时限，实践通常 1–3 个月，取决于补正轮次。

## 四、材料的三层结构

主体信息（beian.cac.gov.cn 表单）→ 备案信息（算法、产品）→ 产品及功能信息。主体信息审核通过才能登记备案信息。

**主体信息表单**：9 项文字信息（名称、信用代码、注册地、月活等）+ 法人、算法安全责任人、联系人三块 + 6 件上传文件（营业执照 PDF、两份证件照、三份盖章件——工作证明、承诺书、落实算法安全主体责任基本情况，模板均在表单内下载）。

**落实算法安全主体责任基本情况**是主材料，结构三大节：算法安全专职机构 → 五项制度（自评估、监测、应急、违法违规处置、其他）→ 附件。

## 五、实战口径（我们踩过/避开的点）

1. **专职机构不能填议事机构。** 「公司代表大会」这类经营决策机构不是「专职」机构，审核要的是有人天天在岗。正确结构：代表大会**决定设立**算法安全委员会 → 主任决策 → 秘书日常响应——既满足专职要求，又用上现有治理惯例。
2. **附件不能列交不出的文件。** 清单里挂五份不存在的制度文本是典型补正点；材料自洽优先于面面俱到——制度阐述并入正文即可。
3. **编参数要保守。** 委员 5 名不是 50 名、月度抽检不是实时监测、通用手段（关键词库、权限分级、加密）不吹没有的系统。审核不逐项核查，但假到扎眼会引起深挖。
4. **口径一致性是生命线。** 委员人数、抽检频率这些数字一旦提交就是公司正式口径，补正和后续备案必须原样续上——把参数正本存进自己的仓，比记在脑子里可靠。
5. **材料定位是过审，不是立制度。** 别为了交材料顺手立五套制度体系，那是另一件事，别混在一个任务里。
